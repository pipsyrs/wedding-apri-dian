GANTI FILE INI DENGAN LAGU ASLI

File wedding-song.mp3 saat ini hanyalah MP3 SENYAP (placeholder).
Formatnya sudah MP3 valid, tapi tidak ada suaranya.

Cara mengganti:
1. Siapkan file MP3 lagu yang diinginkan.
2. Timpa public/audio/wedding-song.mp3 dengan file tersebut
   (pertahankan nama yang sama - tidak perlu mengubah kode sama sekali).

Bila ingin memakai nama file berbeda, ubah baris `music.src`
di src/data/invitation.js agar menunjuk ke nama baru tersebut.

Saran teknis:
- Bitrate 128 kbps sudah cukup untuk web; hindari file di atas 5 MB
  agar halaman tidak berat dibuka lewat data seluler.
- Pastikan Anda punya hak pakai atas lagu tersebut.
